DUNGEONS II STATS MOD
=====================

Shows hidden weapon and armour stats in your inventory item descriptions.

HOW TO USE
1. Extract this folder anywhere (not in the game folder).
2. Double-click "Start Stats Mod.bat". You can start it before or after the game.
3. Give it a minute or two after the game starts. When the window says "Done",
   hover any item in your inventory.

Run it each time you start the game. You can minimise its window while playing.
Press R in the window to scan again if an item is missing stats.

--------------------------------------------------------------

- It doesn't change any game files. It adds the stats to the item text in memory while
  the game runs, and closing the game puts everything back to normal.
- The numbers are base values. In game, damage is also scaled by Item Power and effects.
- Some antivirus software may flag it, because it edits the game's memory (like trainers
  and overlays do). The full source code is on GitHub.
- It only changes text on your screen. Other players see nothing, and it doesn't affect
  gameplay. Use at your own risk.
